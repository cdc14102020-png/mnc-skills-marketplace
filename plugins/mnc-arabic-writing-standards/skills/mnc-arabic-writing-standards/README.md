# mnc-arabic-writing-standards

مهارة مرجعية لمعايير الصياغة اللغوية والإملائية والتحرير العربي السليم، لاستخدامها من قِبل الوكلاء الذكيين حصرًا عند كتابة أو مراجعة أي نص إداري رسمي (إجراءات، خطابات، تقارير، محاضر اجتماعات) نيابة عن المركز.

## المصادر

- **دليل الكتابة الإدارية** (الإصدار الثاني، ١٤٤٦هـ) — أصول الكتابة الإدارية، والضوابط العامة للصياغة، وضوابط الإملاء، والخطاب الإداري.
- **الوثيقة المرجعية اللغوية للوكلاء الذكيين** — مستندة إلى: دليل الكتابة الإدارية، كتاب الإملاء (حسين والي)، وكتاب فن التحرير العربي (محمد صالح الشنطي).
- قواعد **تعريب الألفاظ الأجنبية** المتعارف عليها في مجامع اللغة العربية ومعاجم الأخطاء الشائعة (خصوصًا ضبط همزة الكلمات المعرَّبة مثل "إستراتيجية").
